## 1. สิ่งที่ต้องเตรียม

**ฝั่งเซิร์ฟเวอร์**
- เครื่องที่ติดตั้ง [Docker](https://www.docker.com/) และ Docker Compose ได้ (เช่น Raspberry Pi, VPS, หรือเครื่องคอมพิวเตอร์)
- บัญชี [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) (ใช้แผนฟรีได้)
- OAuth Application ที่ลงทะเบียนไว้กับระบบ SSO ของมหาวิทยาลัย (ได้ Client ID, Client Secret)
- โดเมนของตัวเอง (แนะนำ ไม่บังคับ หากทดสอบในวง LAN เท่านั้น)

**ฝั่งฮาร์ดแวร์ (ต่อ 1 ห้อง)**
- บอร์ด ESP32 Dev Module
- จอแสดงผล LCD I2C ขนาด 16x2
- โมดูลรีเลย์ 1 ช่องสัญญาณ
- กลอนประตูไฟฟ้าโซลินอยด์
- ปุ่มกด (Push Button)
- แหล่งจ่ายไฟและโมดูลแปลงไฟ (Buck Converter)
- [Arduino IDE](https://www.arduino.cc/en/software) พร้อมติดตั้งไลบรารี `WebSockets` (Markus Sattler), `ArduinoJson`, `LiquidCrystal I2C`

## 2. การติดตั้งเซิร์ฟเวอร์

```bash
git clone <URL ของ repository นี้>
cd smart-door-lock
```

สร้างไฟล์ตั้งค่าจากตัวอย่างที่ให้มา:
```bash
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env
```

เปิดไฟล์ `backend/.env` แล้วกรอกค่าต่อไปนี้ให้ครบ:
```env
MONGODB_URI=<connection string จาก MongoDB Atlas>
JWT_SECRET=<สุ่มข้อความยาวๆ ไม่ซ้ำใคร>
FRONTEND_ORIGIN=https://โดเมนเว็บของคุณ
SSO_CLIENT_ID=<จากระบบ SSO มหาวิทยาลัย>
SSO_CLIENT_SECRET=<จากระบบ SSO มหาวิทยาลัย>
SSO_REDIRECT_URI=https://โดเมนเว็บของคุณ
SSO_AUTHORIZE_URL=<URL endpoint ของ SSO>
SSO_TOKEN_URL=<URL endpoint ของ SSO>
SSO_USERINFO_URL=<URL endpoint ของ SSO>
ESP32_WS_HOST=<โดเมนของ backend>
ESP32_WS_PORT=443
ESP32_USE_TLS=true
```

เปิดไฟล์ `frontend/.env` กรอก URL ของ backend:
```env
VITE_API_URL=https://api.โดเมนของคุณ
```

รันระบบด้วย Docker Compose:
```bash
docker compose up --build -d
```

ตรวจสอบว่าระบบทำงานแล้วโดยเปิด `https://api.โดเมนของคุณ/api/health` ควรได้ `{"status":"ok"}`

## 3. การตั้งค่าครั้งแรก (สร้างแอดมิน)

เนื่องจากระบบบังคับให้ล็อกอินครั้งแรกผ่าน SSO เท่านั้น จึงต้องสร้างบัญชีแอดมินคนแรกผ่านคำสั่งพิเศษ (ไม่ผ่านหน้าเว็บ):

```bash
docker compose exec backend node src/seedAdmin.js <username ที่ต้องการ> <รหัสผ่านที่ต้องการ>
```

ตัวอย่าง:
```bash
docker compose exec backend node src/seedAdmin.js myadmin StrongPass123
```

จากนั้นเข้าเว็บไซต์ → กด "เข้าสู่ระบบด้วยรหัสผ่าน" → กรอก username/password ที่เพิ่งสร้าง → จะเข้าสู่ระบบในฐานะแอดมินทันที

## 4. การเพิ่มห้องและตั้งค่าอุปกรณ์ ESP32

1. เข้าสู่ระบบด้วยบัญชีแอดมิน → ไปที่เมนู **จัดการห้อง**
2. กรอกชื่อห้อง ชื่อ/รหัสผ่าน WiFi ของสถานที่ติดตั้ง และเวลาที่ต้องการ (เวลานับถอยหลังรอกดปุ่ม, เวลาปลดล็อกค้างไว้)
3. กด **"เพิ่มห้อง"** — ระบบจะสุ่มรหัสลับ (secret) เฉพาะห้องนี้ให้อัตโนมัติ
4. กดปุ่ม **"ดาวน์โหลด .ino"** ที่การ์ดของห้องนั้น จะได้ไฟล์โค้ดที่กรอกค่าทุกอย่างมาให้ครบแล้ว **ไม่ต้องแก้โค้ดเองเลย**
5. เปิดไฟล์ `.ino` ที่ดาวน์โหลดมาด้วย Arduino IDE
6. เลือกบอร์ด "ESP32 Dev Module" และพอร์ต USB ที่ถูกต้อง แล้วกด Upload
7. กดปุ่ม **"QR Code"** เพื่อสร้าง QR สำหรับพิมพ์ติดหน้าห้องนั้น

**หากต้องการเปลี่ยนค่า WiFi หรือเวลาทีหลัง:** กดปุ่ม "ตั้งค่า WiFi/เวลา" ที่การ์ดห้อง แก้ค่าใหม่ แล้วดาวน์โหลดไฟล์ `.ino` ใหม่อัปโหลดทับของเดิมอีกครั้ง

## 5. การติดตั้งฮาร์ดแวร์

เชื่อมต่อสายไฟตามตารางนี้ (รายละเอียดเพิ่มเติมอยู่ในตัวเล่มโครงงาน บทที่ 3.2):

| จาก | ไป | หมายเหตุ |
|---|---|---|
| ESP32 GPIO21/GPIO22 | LCD SDA/SCL | สื่อสารผ่าน I2C |
| ESP32 GPIO14 | โมดูลรีเลย์ IN | สัญญาณควบคุม |
| ESP32 GPIO27 + GND | ปุ่มกด | ยืนยันตัวตนทางกายภาพ/รีเซ็ต |
| รีเลย์ COM/NO | กลอนประตูโซลินอยด์ | ผ่านวงจรไฟ 12V แยกต่างหาก |

**คำเตือน:** ต้องแยกแหล่งจ่ายไฟของกลอนประตูออกจาก ESP32/LCD (ยังคงต่อกราวด์ร่วมกัน) เพื่อป้องกัน ESP32 รีเซ็ตตัวเองขณะกลอนประตูทำงาน

## 6. วิธีใช้งานสำหรับผู้ใช้ทั่วไป

1. เปิดเว็บไซต์ หรือสแกน QR Code ที่ติดไว้หน้าห้อง
2. กด **"เข้าสู่ระบบด้วย SSO มหาวิทยาลัย"** แล้วกรอกบัญชีมหาวิทยาลัยตามปกติ
3. (ครั้งแรกเท่านั้น) ตั้งรหัสผ่านสำหรับเข้าใช้งานครั้งถัดไปโดยไม่ต้องผ่าน SSO ก็ได้ หรือกดข้ามได้
4. เลือกห้องที่ต้องการ กด **"ขอสิทธิ์"**
5. **เดินไปที่หน้าห้อง แล้วกดปุ่มที่ติดตั้งไว้ภายใน 10 วินาที** ประตูจะปลดล็อก 5 วินาทีแล้วล็อกกลับอัตโนมัติ

**หากห้องไม่มีอินเทอร์เน็ต:** กดปุ่มที่หน้าห้อง 1 ครั้ง → ต่อ WiFi ชื่อ "DoorLock-Offline" ด้วยมือถือ → กรอกรหัสฉุกเฉิน 6 หลักที่ได้รับจากแอดมิน

## 7. วิธีใช้งานสำหรับแอดมิน

| เมนู | ใช้ทำอะไร |
|---|---|
| จัดการห้อง | เพิ่ม/แก้ไข/ลบห้อง, ดาวน์โหลดโค้ด ESP32, สร้าง QR Code, ตั้งสิทธิ์อัตโนมัติตามคณะ/สาขา, จัดการรหัสฉุกเฉิน |
| จัดการผู้ใช้ | ค้นหา ดูรายละเอียด กำหนดสิทธิ์ห้องรายบุคคล เปลี่ยนบทบาท |
| ประวัติการใช้งาน | ตรวจสอบย้อนหลังว่าใครปลดล็อกห้องไหน เมื่อไหร่ |

## 8. การแก้ปัญหาเบื้องต้น

| อาการ | สาเหตุที่เป็นไปได้ | วิธีแก้ |
|---|---|---|
| ESP32 เชื่อมต่อไม่ติด | WiFi/secret ผิด | ดาวน์โหลดไฟล์ `.ino` ใหม่จากหน้าเว็บ อัปโหลดทับอีกครั้ง |
| จอ LCD ขึ้น "Server offline" | Backend ล่ม หรือเน็ตของห้องมีปัญหา | เช็คสถานะ container ด้วย `docker compose ps` |
| หน้าเว็บขึ้น error SSO | Login callback ไม่ตรงกับที่ลงทะเบียนไว้ | ตรวจสอบค่า `SSO_REDIRECT_URI` ให้ตรงกับที่แจ้งไว้กับมหาวิทยาลัยเป๊ะ |
| ลืมรหัสผ่านแอดมิน | - | รัน `seedAdmin.js` ซ้ำด้วย username เดิม จะรีเซ็ต role เป็น admin ให้ (ไม่รีเซ็ตรหัสผ่าน ต้องตั้งใหม่ผ่านหน้าเว็บ) |

หากพบปัญหาอื่นนอกเหนือจากนี้ ติดต่อผู้ดูแลระบบตามช่องทางที่แสดงในเว็บไซต์ (ปุ่ม "ติดต่อแอดมิน")
